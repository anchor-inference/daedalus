# Animated screenshots

Short tours assembled from the current browser captures of the same invented installation. Run `tests/browser/screenshots.py` for the English set before `tests/browser/animated_shots.py`; the latter makes five 1200 × 675 GIFs from the named stills, with dissolves between scenes.

| File | Where in the README | What it shows |
|---|---|---|
| `browser.gif` | the picture at the top | Browser live view, operator takeover, control returned, and replay. |
| `session.gif` | How it looks — a session | Answer, workspace files, file preview, and browser panel. |
| `orchestration.gif` | How it looks — orchestration | Main orchestrator, project focus, project questions, and board. |
| `phone.gif` | How it looks — on a phone | Agents, session, browser sheet, project, and More sheet. |
| `selfdev.gif` | Self-development | Changes list, proposed change summary with approval action, and diff. |
