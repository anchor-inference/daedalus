# Animated screenshots

Sped-up recordings of the same invented installation the still screenshots are taken over. Each is 1200 px wide, 15 frames a second, with a palette of its own.

| File | Where in the README | What it shows |
|---|---|---|
| `browser.gif` | the picture at the top | The agent's own browser, live, with the actions it took: the operator takes control, leaves a note for the agent and gives the browser back. |
| `session.gif` | How it looks — a session | A session: the agent's answer with its checks and the files it sent, the steps it took opened and scrolled through, and the panel's Browser tab, where the agent searches a shop, picks a size and adds it to the cart while its actions are listed. |
| `orchestration.gif` | How it looks — orchestration | The main orchestrator's chat: a project's question answered in the Questions tab and sent. Then a project from the column: its goal line opens the work in hand and the results waiting for a decision, a result handed in opens on the board with its review — branch, commits, files, checks — and its diff, and the merge of the reviewed branch is requested. |
| `phone.gif` | How it looks — on a phone | The same app on a phone: the agents, a session with its answer, and the agent's browser as a sheet. Then the Orchestration tab and a project, with its own bar along the bottom — Orchestrator, Board, Team, Terminals — and its More sheet. |
| `selfdev.gif` | Self-development | Changes: a pull request the agent opened against its own code, its summary and diff, approved in the app, merged, and the rebuild started. |
