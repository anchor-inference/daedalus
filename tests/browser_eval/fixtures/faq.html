Help centre

Orders

How do I change my delivery address?

Open the order and choose "Change address" before it ships.

Can I add a book to an order that has already been placed?

No; place a second order. Shipping is combined if both leave the same day.

Returns and refunds

How long do I have to return a book?

Thirty days from delivery, in the condition you received it.

Can I return an e-book?

Within 14 days, if you have not opened it on any device.

What about gift cards?

Unused gift cards can be refunded within 45 days of purchase. Partly used cards cannot be refunded.

Account

How do I close my account?

Write to the help desk from the address the account uses.
